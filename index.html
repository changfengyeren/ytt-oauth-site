ytt

ytt 是一个供项目所有者个人使用的视频上传工具。它从所有者配置的 OpenList 网盘读取选定的视频，再通过 YouTube Data API 上传到所有者授权的频道。

工作方式

程序运行在所有者管理的 Google Cloud 虚拟机上。视频按块读取和上传。程序保存传输进度，以便在连接中断后继续上传。完整视频不作为临时文件保存在虚拟机中。

Google 账号授权

所有者在 Google 授权页面选择频道，并授予以下权限：

  • youtube.upload：上传所选视频。
  • youtube.readonly：读取频道身份和视频处理状态。

上传默认使用私有可见性。所有者可以在上传命令中选择其他可见性。此页面只介绍应用，不接收账号授权、网盘凭据或视频文件。
